# Examples

AgentLane runnable demos are grouped by category.

## Categories

1. [`throughput/high_throughput_messaging/`](./throughput/high_throughput_messaging/)
   for high-load messaging demonstrations.
2. [`runtime/`](./runtime/) for lifecycle, scheduling, and distributed runtime demos.
3. [`models/`](./models/) for direct provider and models-layer demonstrations.
4. [`harness/`](./harness/) for agent and orchestration demonstrations.

## How To Use This Directory

Each demo has its own README with the exact commands to run it. The
`runtime/`, `models/`, and `harness/` categories also have a category-level
README that lists the demos they contain.

## Environment

Some examples require provider API keys such as `OPENAI_API_KEY` or
`ANTHROPIC_API_KEY`. The category READMEs call that out where needed.
